# Design

The hosted Documents API adds closed POST actions for review, register and export. Candidate-bound catalog IDs select inputs; users cannot supply filesystem paths. GET remains read-only. Registration runs in a separate bounded process under the upstream canonical tracker lock, so set-status and other tracker writers contend on the same lock. A private write-ahead journal records exact report/tracker/ledger bytes and replays only an expected before/after hash, with private tracker backups and idempotent document receipts. Row numbers account for existing report numbers. Dynamic tracker column maps are preserved. No existing row/status is replaced.

Quality review snapshots selected source, current primary revision, original direct statements and optional evaluation/JD; an integrity fingerprint is required for export to reject changed inputs. Resume-only mode selects a recognized Markdown Resume/Tailored resume section and refuses absent/ambiguous sections. Title checks parse the upstream canonical company/title/dates format and clearly report incomplete coverage. Keyword coverage is diagnostic only, and missing JD/keywords is not a pass. Numeric comparisons are conservative diagnostics, not semantic verification; job data and derived notes are excluded as factual sources. Human acknowledgment cannot promote a fact to a primary file.

PDF uses existing playwright-core and the VPS Chromium executable with JavaScript disabled and all network requests denied. Escaped Markdown is rendered as single-column text with headings, lists, wrapping, US Letter margins and page numbers. Exported PDFs/check notes are immutable by source/check hash. Filenames are server-derived. No remote fonts/images/HTML execution. PDF export does not mark an application sent or alter tracker PDF fields.
