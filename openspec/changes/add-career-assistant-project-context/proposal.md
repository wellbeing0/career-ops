## Why

Commit a compact four-document project guide. Package its hashes, exact source commit and release identifier with every deployment. Supply validated deployed guides and bounded candidate-specific read-only search/filter/pipeline/application summaries each turn. Keep explanatory project/operational data separate from candidate primary facts. Use the existing application prompt adapter; no new native tools, general repository checkout or plugin is required.
