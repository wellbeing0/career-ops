## ADDED Requirements

### Requirement: Guidance visible on a phone
The site index SHALL place two workspace buttons at the top and the workflow immediately below, without the promotional introduction, workspace cards or duplicate shortcuts.

#### Scenario: Candidate opens the guide on iPhone
- **WHEN** the guide is opened at a 390-pixel phone width
- **THEN** both workspace buttons and the first workflow steps are visible without horizontal scrolling

### Requirement: Live workspace navigation
Each workspace SHALL link back to the root Job-search guide instead of the obsolete static archive index. Publication SHALL remove candidate static index pages while preserving archive documents and live-library archive access.

#### Scenario: Candidate wants guidance or an archived file
- **WHEN** the candidate uses the workspace navigation
- **THEN** Job-search guide opens the root index and Documents continues to expose dated archive files
