# Design

Reuse the existing detached Assistant runner and conversation receipts. The server validates a closed workflow selector, saved-opportunity URL (when selected), full JD size and interview round/date inputs. No user-chosen mode filename or arbitrary output path reaches the worker. Reviewed public mode prompts supply procedures; a hosted adapter explicitly replaces unavailable CLI/browser/research actions and filesystem instructions. Mode prompts are system code, candidate targeting remains private primary data.

Evaluation/interview produce review material with immutable run-specific filenames and an archived JD; they never become primary accomplishment sources. Application uses the existing guarded draft save and unsupported-number gate. Every result links to Documents; retry/recovery verifies exact saved bytes. Interview references include the candidate's retracted-claims and question bank as derived context, not factual authority.

Source repair uses exact old addresses, private filter history, preserved unrelated targeting and candidate-owner writes. W&B's observed dedicated feed may be enabled; HubSpot/Hightouch use official manual pages until a feed is proven. Existing searches remain historical. Steve-only model alignment preserves all other configuration and private rollback.
