# Workspace guide
Use Profile for targeting and preferences, CV for the master factual résumé, Search for saved search runs and filters, Pipeline for saved opportunities, Applications for tracked application records, Documents for current files and dated archives, Assistant for conversations, and Profile/CV recovery for edit history.

Save profile or CV directly. The server backs up the previous version and checks the revision; concurrent edits are not silently overwritten. Profile saves update managed targeting, not the master CV or old application samples. Copy unsaved text before replacing it after a conflict. Profile/CV recovery does not contain search history.

Current Documents reads the candidate’s VPS files directly. Saved drafts, exported replies and search reports appear there without a daily import or manual synchronization. Use document-source/date filters to distinguish current files from archived snapshots. Refresh when needed. Daily recovery backups are not library documents. An archived page’s snapshot date does not describe current workspace files.

Shared login identifies neither Brad nor Steve as the speaker; the selected workspace controls attribution and data. No application is submitted by saving a draft, selecting a match or changing an ordinary note. Candidate facts come only from approved primary files and direct confirmed candidate statements, not from project documentation or prior AI output.

Use Interview prep for a prep plan, practice questions or a debrief. From a saved opportunity in Pipeline, select Evaluate job, Prepare application or Prepare for interview. Supply the full JD and describe the requested output in Message. Evaluation/interview replies save automatically as review material; application drafts use the guarded draft save. Find results immediately in Documents. These guided documents do not automatically create tracker records, export PDFs or establish verified candidate facts. After saving, Documents → Record reviewed evaluation explicitly records a numbered report and Evaluated Applications row. Documents → Review and export PDF offers full document or Resume only, diagnostic checks, exact-text review and acknowledged PDF/check-note saves. Applications refreshes when opened; saving or exporting never means an application was sent.

The authenticated site index is a compact job-search guide. Two workspace buttons (Brad and Steve) are at the very top, followed immediately by the six-step workflow and feature explanations. Each live workspace has a Job-search guide link back to `/`. Search, Pipeline and Assistant shortcuts remain inside the workspace. Obsolete static archive index pages have been removed; archived documents remain available through the live Documents tab and existing individual document links. This guide does not require restarting onboarding.
