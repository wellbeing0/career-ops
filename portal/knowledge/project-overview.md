# Career Ops project overview
Repository: https://github.com/wellbeing0/career-ops
Upstream: https://github.com/career-ops-hq/career-ops
Website: https://careerops.steveleclair.info

This is Steve’s hosted adaptation of Career Ops. Brad and Steve have separate candidate workspaces behind an approved shared login. The VPS holds authoritative profiles, CVs, applications, searches, documents and conversations. Mac copies and the original document portal are dated backups/archives. Repository code is separate from private candidate data.

The hosted website has deliberately bounded capabilities; an upstream CLI feature does not automatically exist in this website. Explain the deployed guide and supplied workspace snapshot. Never claim to have checked GitHub, fetched a posting or inspected live services unless the request supplies that evidence. Release metadata identifies the code/docs deployment, not the date candidate facts were verified.

The web server sends candidate-bound context to dedicated OpenClaw career-brad or career-steve agents. OpenAI is configured first with existing OpenRouter fallback; account-level spending controls remain with Steve. Native model tools are denied. Supported operations are implemented by the website’s bounded server helpers. These project docs explain the product; they never establish candidate achievements, authorship or compensation facts.

The current hosted increment adds explicit post-save evaluation registration and PDF export in Documents. Public context guides are reviewed and updated for each deployment and packaged with a source-commit/hash manifest; they are supplied to both career assistants without copying private candidate facts into the repo.

The authenticated site index is a concise re-entry guide: choose Brad or Steve, jump to Find jobs (Search), Saved opportunities (Pipeline) or Ask Assistant, and follow the six-step job-search path when helpful. Profile/CV, Search, Pipeline, evaluation, application preparation, manual application/status tracking and interview preparation are explained there. It is a navigation guide, not a live dashboard or a requirement to restart onboarding.
